## 🔧 Quick Wins

1. **Google Search Console**
   ```
   Add verification code to <head>:
   <meta name="google-site-verification" content="YOUR_CODE" />
   ```

2. **Submit Sitemap**
   ```
   https://auroriqa.com/sitemap.xml
   ```

3. **Create og-image.jpg**
   - Size: 1200x630px
   - Format: JPG/PNG
   - Location: /public/og-image.jpg

4. **Create favicon**
   - Generate at https://realfavicongenerator.net/
   - Add to /public/
